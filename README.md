# DispatchNode MCP

Public connect config for the hosted DispatchNode Model Context Protocol server.

- Endpoint: https://www.dispatchnode.com/api/mcp
- Docs: https://www.dispatchnode.com/docs/mcp
- Product: https://www.dispatchnode.com/mcp

Auth uses Clerk OAuth. After connecting, call `list_orgs`, then `set_organization`.

This repository is a directory wrapper only. It is not a source extract of the DispatchNode product monorepo.
